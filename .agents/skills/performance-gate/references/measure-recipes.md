# Measure recipes

One number before, one after, same method, same machine state. Record both in the verdict block. Take the median of 3 runs for anything under 1 second.

| Question                  | Method                                                                                                                                                                                                                                                 | Where                         |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------- |
| Is the bundle bigger?     | Build twice (stash the change), compare output size of the changed entry; `pnpm build` output or the bundler's size report                                                                                                                             | Leonidas Code web and desktop |
| Is startup slower?        | Time from process launch to first interactive frame or "ready" log line; `Measure-Command` around the launcher                                                                                                                                         | Both                          |
| Is a function slower?     | Micro-benchmark with the language timer on realistic input; Python: `python -m timeit` or `time.perf_counter`; TS: `performance.now` over 1000 iterations                                                                                              | Both                          |
| Where does time go?       | Python: `python -m cProfile -o out.prof` then `pstats`; Node and Electron: `--cpu-prof` and open the `.cpuprofile` in DevTools                                                                                                                         | Both                          |
| Is memory growing?        | Repeat the action 20 times, force GC, compare heap. Node and Electron: DevTools heap snapshots before and after, per [`memory-leak-debugging`](../../memory-leak-debugging/SKILL.md). Python: `tracemalloc` snapshot diff, or process RSS via `psutil` | Both                          |
| Did a render regress?     | React Profiler commit count and duration for the interaction; count re-renders of the touched component before and after                                                                                                                               | Leonidas Code web             |
| Is traffic heavier?       | Count bytes and messages per interaction on the WebSocket or IPC channel before and after                                                                                                                                                              | Leonidas Code server          |
| Is the UI thread blocked? | Longest task over 50 ms in the DevTools Performance tab; Qt: log the duration of every slot on the main thread, none should exceed 50 ms                                                                                                               | Both                          |

Budgets that fail the gate unless the owner accepts the risk: any added main-thread task over 50 ms, any steady memory growth across 20 repeats, startup slower by more than 10 percent, any bundle growth over 5 percent of the touched entry without a feature that needs it.
