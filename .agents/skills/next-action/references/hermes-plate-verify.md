# Verify delegated work

Treat a worker's summary as claims to check. Read the task's acceptance criteria and the worker's changed artifacts. Re-run the smallest independent checks that could refute each material claim, including cited tests or live behavior when authorized.

Record verified results and discrepancies. Keep work awaiting review when approval is required; return specific failed checks to the worker only through an authorized delegation path. Do not accept or dispatch a worker merely because this reference exists.
