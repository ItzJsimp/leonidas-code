# Keep one set of website logins across AI accounts

Shared browser gives supported AI accounts one dedicated website profile.
Sign in to your sites once in that profile, then use those logins across accounts.

## Connect from Browser settings

Open **Settings > Browser**, select the computer, and turn on **Shared browser**.
Select **Open shared browser** to check startup and open the browser in a chat.
You enter passwords, complete verification, and handle CAPTCHA yourself.

The profile lives on the selected computer, including when you connect from a phone.
Your normal Chrome profile and ordinary Preview profiles keep separate sign-ins.
Providers need Leonidas Code Preview tools to use the shared profile.

## Disconnect without losing sign-ins

Turning off Shared browser blocks existing agents from the profile and hides its page details.
Saved website logins stay on the computer for the next connection.
The main AI browser access switch also blocks the shared profile.

The [setup guide](../docs/user/shared-browser.md) covers connection checks and troubleshooting.
