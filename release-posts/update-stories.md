# Updates worth opening

See what changed in Leonidas Code, with pictures and short explanations. Open any update to read what's new and what's been fixed.

![An update open beside a list of earlier versions](update-reader.png)

## A home for every update

Update history now shows a list of updates, each with a date and a short explanation. Pictures help show new features when an update includes them.

Open update history from the version number in the sidebar, the sidebar's history button, Settings, or the command palette.

## Browse first, then read

Choose **Read update** for the full explanation. On a larger screen, earlier versions stay beside it so you can switch between updates. On a small screen, choose **All updates** to return to the list.

New features get their own explanations and pictures, followed by a short list of other changes. You can still read the original notes for older updates.

## A calmer update notice

The update notice starts with five highlights. Show more changes or choose **Full notes** to read everything before installing. Update buttons stay together at the bottom.

**Update when safe** waits for running agents to finish. **Restart now** keeps the existing confirmation when an agent is running. Reading a patch note never starts a chat or installs an update.

If the full explanation cannot load, you can still read the highlights and try again later.
